# Audited data contract

The runtime source of truth is
`artifacts/dataset_audit/subset150_contract.json`, generated by
`tools/inspect_dataset.py`. It records the manifest path/hash, key source metadata
hashes, actual band descriptions, dtype/nodata, 256×256 shape, 20 m resolution,
EPSG:27704 CRS, split counts, mask encoding, safe/disabled QA, and scientific
semantics.

The audit checks all 150 manifest rows and all 11 raster groups per row for existence,
unique correspondence, basename, band schema, shape, CRS, affine alignment, dtype,
nodata, dataset/per-band masks, finite values, and valid ranges. Three distributed
samples per split receive detailed records. Any dataset write lock, missing file,
manifest count mismatch, modality grid mismatch, band-semantic mismatch, non-finite
valid value, or label/mask mismatch makes the command exit nonzero.

Observed mask true values can be encoded as 1 or 255; runtime uses `value > 0`.
`depth_m` has nodata -9999 and is already in metres. The loader fills invalid target
tensor cells with 0 only for numerical safety and always gates supervision with
`valid_depth_mask`.

The provided normalization metadata was not selected because it lacks p0.5/p99.5
robust clipping quantiles. `subset150_train_stats.json` was therefore computed from
valid train pixels only and fingerprint-bound to the contract. No source data file is
modified and no cache is written beneath the dataset root.
