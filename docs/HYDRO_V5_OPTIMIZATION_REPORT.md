# Hydro-v5 任务定制优化报告

> 本文档是第一轮冻结记录。后续损失函数和物理约束结果见
> `docs/HYDRO_V6_LOSS_PHYSICS_REPORT.md`。

## 结论

Hydro-v5 已完成一次全量训练和独立验证集复评。相对用户原始
Hydro-v1 最佳权重，在完全相同的验证样本、深度分层和评价代码下：

| 验证指标 | Hydro-v1 | Hydro-v5 | 变化 |
|---|---:|---:|---:|
| 事件-层级深度复合 MAE (m) | 0.36452 | **0.33337** | **-8.55%** |
| 事件-深度层级宏平均 MAE (m) | 0.34880 | **0.30975** | **-11.20%** |
| 事件-精细深度分箱宏平均 MAE (m) | 0.52737 | **0.46890** | **-11.09%** |
| 事件宏平均 MAE (m) | 0.38023 | **0.35698** | **-6.12%** |
| 像元 MAE (m) | 0.61421 | **0.56799** | **-7.52%** |
| 像元 RMSE (m) | 0.92772 | **0.87687** | **-5.48%** |
| 像元 bias (m) | -0.52473 | **-0.45663** | 绝对偏差 **-12.98%** |
| 像元 R² | -0.49470 | **-0.33535** | +0.15935 |
| Laplace NLL | 2.64765 | **2.43003** | **-8.22%** |
| 90% 区间覆盖率 | 54.69% | **59.33%** | +4.64 个百分点 |

这些结果只来自 `train`/`val`。本轮诊断、训练、模型选择和最终复评
都没有读取 `test` 分割。

## 为什么这样优化

这次没有使用通用的“加深网络、换优化器、加数据增强”策略，而是针对
事件聚合洪水深度回归的标签语义和长尾分布做修正。

1. **先分离“有效正水深”与“支持区域”。** `valid_depth_mask` 只能支持正水深
   监督，未标注像元不能被当作 0 m 负样本。Hydro-v5 的主回归量保持为
   `conditional_positive_v2`，不再用未完全标定的 support probability 衰减可靠
   正水深。
2. **将原来过宽的深水层细分。** 旧的 0.48--24.82 m 层把普通深水与极端
   深水混在一起。新边界只由训练集正水深分位数产生：
   `0.10, 0.23, 0.48, 0.83, 1.22, 2.14, 24.82 m`。
3. **使用层级损失，而非平铺的六分箱等权。** 先在原始浅/中/深主层内对细分
   单元等权平均，再对非空主层等权平均，最后按事件宏平均。这避免了
   因深水层被分成四段而在优化中获得四倍隐性权重。
4. **模型选择同时关心事件和水深层。** 新的最佳权重监控量为
   `0.5 * (event_macro_mae + event_depth_hierarchical_macro_mae)`，两项都以米为
   单位，不会被大面积事件或深水细分数量主导。
5. **训练采样按事件交错且每轮精确遍历一次。** 这与事件宏平均目标一致，
   同时避免有放回加权采样重复某些 patch。

辅助诊断也限制了方案范围：全局 S1/S2 统计与事件平均水深的训练集
Spearman 相关最高仅约 0.28，因此没有添加易记忆小样本事件的全局 stage MLP。
反事实推理中，去掉 Terrain Graph-KAN、仅保留 S1、仅保留 S2 或仅保留地形都会
使验证误差上升，因此保留了异步双模态和地形图融合主干。

## 分水深结果

| 训练集冻结水深区间 (m) | 验证像元数 | Hydro-v1 MAE | Hydro-v5 MAE | 变化 |
|---|---:|---:|---:|---:|
| `<= 0.23` | 44,374 | **0.14149** | 0.16153 | **+14.17%** |
| `(0.23, 0.48]` | 32,594 | 0.17103 | **0.11844** | **-30.75%** |
| `(0.48, 0.83]` | 25,830 | 0.36342 | **0.29242** | **-19.54%** |
| `(0.83, 1.22]` | 31,662 | 0.72787 | **0.64612** | **-11.23%** |
| `(1.22, 2.14]` | 30,443 | 1.29479 | **1.22739** | **-5.21%** |
| `> 2.14` | 9,047 | 2.55757 | **2.47575** | **-3.20%** |

主要收益位于 0.23--2.14 m，正好对应原模型宽深水层中的系统性低估。
但这不是“所有水深都变好”：最浅层 MAE 有所上升，而 `>2.14 m` 虽比原始
模型略好，仍存在 -2.475 m 左右的强烈低估。

## 尚未解决的问题

- 像元 R² 仍为负，说明当前 subset150 上还不能宣称完成高质量绝对水深重建。
- `>2.14 m` 极端尾部仍严重低估，它只有 9,047 个验证像元，并且事件间分布不均。
- 最浅层为换取中深水改善付出了误差代价；因此不应只用单一像元 MAE
  来描述这次更改。
- 90% Laplace 区间实际只覆盖 59.33%，不确定性仍明显过度自信；不确定度-误差
  Spearman 相关从 0.2837 降到 0.2557。
- 正水深区域 WSE Laplacian 从 0.04826 升到 0.05443，高起伏区连续性诊断从
  0.03128 升到 0.08726。数值精度改善不等于物理一致性已改善。

下一步若继续研究，应优先做“浅水边界与极端深水事件分开约束”的预注册消融，
而不是盲目扩大模型。在模型、阈值和评价方案真正冻结前，不应开启测试集。
